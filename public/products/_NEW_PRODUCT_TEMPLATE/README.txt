Шаблон нового товара

В этой папке:
- index.html — шаблон отдельной страницы товара
- images/ — сюда складывать фотографии
- PRODUCT_DATA_TEMPLATE.txt — готовый блок для js/products-data.js

Как использовать:
1. Скопируйте всю папку _NEW_PRODUCT_TEMPLATE
2. Переименуйте папку в slug товара, например kama-300x150
3. Переименуйте и замените фото в папке images
4. Возьмите блок из PRODUCT_DATA_TEMPLATE.txt
5. Вставьте его вместо любого черновика product-05 ... product-40
6. Поставьте active: true
