План правки поиска в шапке

1. Вернуть прежнюю ширину раскрытия
- Убрать последнее расширение до `min(520px, 42vw)`.
- Вернуть компактную ширину раскрытой кнопки примерно как было раньше: около `300px` на десктопе, адаптивно меньше на узких экранах.
- Выпадающий список сделать по ширине раскрытой кнопки, чтобы не было визуального разнобоя.

2. Исправить Lottie при наведении
- Поднять/выровнять контейнер `.search-lottie`, чтобы анимация стояла ровно в центре круглой кнопки, а не была «низкой».
- Не трогать сам файл `/lottie/search.json` и загрузку Lottie — только позиционирование и размер контейнера.
- Сохранить поведение: обычная лупа → при наведении появляется Lottie → при клике кнопка плавно раскрывается.

3. Убрать лишнее окно-подсказку
- При пустом поиске больше не показывать блок `Начните вводить название, тип или размер…`.
- Выпадающее окно результатов не должно появляться пустым сразу при открытии.
- Результаты показывать только когда пользователь начал вводить запрос; сообщения `Уточните запрос…` и `Ничего не найдено…` оставить только после ввода.

4. Проверка
- Проверить на текущей ширине превью около 807px: hover показывает Lottie ровно по центру круглой кнопки.
- Клик раскрывает поле прежней ширины, без лишней подсказки снизу.
- Ввод текста показывает результаты/сообщения, закрытие и Escape работают как раньше.

Файлы для изменения:
- `public/css/style.css`
- `public/js/main.js`
