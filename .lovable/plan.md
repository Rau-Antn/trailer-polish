## Что сейчас не так

Сейчас кнопка поиска при клике открывает отдельное всплывающее окно сверху страницы (`.search-popover` на всю ширину), а не разворачивается сама в поле ввода. При этом в светлой теме плашка с Lottie иногда не показывается из-за конфликтов фона/контраста и её на тач-устройствах принудительно режут до 40px (`!important`), что мешает раскрытию.

## Что вернуть (как было)

1. **Круглая кнопка 40×40** в шапке справа, рядом с переключателем темы.
2. **Наведение** → SVG плавно затухает, проигрывается **Lottie-анимация** лупы (файл `public/lottie/search.json` уже есть).
3. **Клик по кнопке/анимации** → сама кнопка плавно растягивается в горизонтальную «таблетку» (~280–320px) с инпутом внутри. Lottie остаётся слева как декоративная иконка, курсор сразу в поле.
4. **Ввод текста** → под кнопкой выпадает компактный список найденных товаров (как сейчас, та же логика `renderResults` со словарём синонимов).
5. **Клик вне / Esc** → плавно сворачивается обратно в круглую кнопку, Lottie останавливается.
6. **Светлая и тёмная темы** — единый стиль кнопки, корректные цвета границы/фона/текста инпута в обеих темах.
7. **Без поломок остального**: эффект «фары» в логотипе, тема, анимации — не трогаю.

## Технические детали

- Файл `public/js/main.js`, функция `initHeaderSearch` (≈ строки 950–1200): перестроить так, чтобы инпут и панель результатов вставлялись **внутрь самой кнопки/её обёртки** (а не в `document.body` как `position:fixed`). Открытие = `aria-expanded="true"` + класс `is-open` на обёртке; закрытие — наоборот.
- Файл `public/css/style.css`, блок `.search-toggle` (≈ 3322–3445): убрать поведение «фуллскрин-попап», оставить плавное расширение ширины кнопки (`width`, `padding`, `border-radius`) на cubic-bezier, корректные стили для `.search-toggle .search-input` и `.search-toggle .search-results` (выпадающий список абсолютным позиционированием под кнопкой).
- Удалить/смягчить правило `@media (hover:none){ .search-toggle{ width:40px !important } }` — оставить ограничение только для невыбранного состояния, иначе на тач/узком вьюпорте кнопка не расширится.
- Светлая тема: единый набор цветов внутри `body.light-theme .search-toggle` (фон `#fff`, бордер `rgba(20,40,70,.15)`, текст `#1a2332`, плейсхолдер `#5a6878`) — без перекрытий из старых правил popover.
- Lottie-инициализация через `ensureLottie()` остаётся как есть; на всех страницах (`index.html`, `catalog.html`, `about.html`, `contacts.html`, карточки товаров) кнопка вставляется тем же `initHeaderSearch` — отдельных правок HTML не нужно.

## Проверка после правок

- Открыть превью на десктопе и на мобильном вьюпорте, в обеих темах.
- Hover → Lottie играет; click → кнопка плавно становится полем; ввод → список товаров; Esc/клик вне → плавно сворачивается.
- Убедиться, что эффект «фары» на логотипе и текущая разметка шапки не сместились.
