## Что не так сейчас

- Меню переносится на **вторую строку** под лого (через `flex-basis:100%` в `.header-inner > nav`), с разделительной линией сверху — выглядит громоздко и «технично».
- Пункты — отдельные «таблетки» с полупрозрачным фоном на hover, без объединяющего контейнера.
- Активный пункт почти не выделен — только тонкая линия снизу (`nav a.is-active::after`), теряется на фоне.

## Что делаем

### 1. Шапка — три зоны в одну строку

```text
[ ЛОГО ]      [ ⌂ Главная · Каталог · О компании · Контакты ]      [ 🌙 ]
   left                       center (capsule)                        right
```

- Лого слева (без изменений — эффект фар не трогаем).
- В центре — **одна стеклянная капсула** (`<nav>`) с пунктами внутри.
- Кнопка темы справа.
- Отменяем правило `flex-basis:100%` для `nav` — больше никакой второй строки на десктопе.

### 2. Стеклянная капсула меню

- Контейнер `<nav>`: `display:inline-flex`, `border-radius:999px`, `padding:4px`, фон `rgba(255,255,255,.04)`, тонкая граница `rgba(255,255,255,.08)`, `backdrop-filter:blur(12px)`, мягкая внутренняя тень.
- Пункты `nav a` внутри: убираем индивидуальные border/фон по умолчанию, оставляем только цвет текста и `padding:7px 16px`. Hover — лёгкий `rgba(255,255,255,.06)` фон внутри капсулы (без рамки).
- Светлая тема: фон капсулы `rgba(10,20,40,.04)`, граница `rgba(10,20,40,.08)`.

### 3. Активный пункт — «свет фар»

Перекликается с эффектом подсветки фары на лого (визуальный язык сайта):

- Фон активной «таблетки»: радиальный градиент от `rgba(130,216,255,.22)` к `rgba(69,185,255,.05)`.
- Тонкая голубая граница `rgba(130,216,255,.35)`.
- `box-shadow: 0 0 18px rgba(69,185,255,.35), inset 0 0 12px rgba(130,216,255,.15)`.
- Цвет текста — белый, с лёгким `text-shadow` голубого свечения.
- Старую анимацию подчёркивания (`navUnderline`) убираем — теперь активность видна по самой капсуле.

### 4. Адаптив (≤ 720 px)

Чтобы капсула не ломалась на узких экранах:

- Уменьшаем `padding` пунктов до `6px 12px`, шрифт `13px`.
- Если всё-таки не помещается в одну строку — капсула может перенестись под лого (текущее поведение `flex-wrap:wrap` на `.header-inner` сохраняем как fallback), но **уже как капсула**, а не как полоса с разделителем сверху. Убираем `border-top` и `padding-top` из мобильного состояния.

### 5. Технические детали

Файлы и места правок (все CSS — без правок HTML):

- `public/css/style.css`, строки **265–286** — переписать базовые стили `nav` и `nav a` под капсулу.
- `public/css/style.css`, строки **2262–2286** (блок «Header layout: actions row OVER nav») — убрать `flex-basis:100%`, `margin-top`, `border-top`, `padding-top` у `.header-inner > nav`; переключить раскладку на `justify-content: space-between` с центральной зоной.
- `public/css/style.css`, строки **2249–2255** (мобильный media-query) — обновить под новое поведение капсулы.
- `public/css/style.css`, строки **3055–3065** (active link) — заменить подчёркивание на свечение капсулы.
- `public/css/style.css`, строки **3113–3114** — обновить активный стиль под светлую тему.

HTML не трогаем — структура `<header><div class="header-inner"><div class="logo-wrap">…</div><nav>…</nav><button class="theme-toggle">…</button></div></header>` уже подходит для трёхзонной раскладки на всех 45 страницах.

Эффект фар на лого (`.headlight-anchor` и слои) — **не трогаем**, как зафиксировано в памяти проекта.

### Проверка после внедрения

- Главная (`index.html`), Каталог, О компании, Контакты — меню в одну строку, активный пункт светится.
- Узкий экран 360–720 px — капсула либо помещается, либо аккуратно переносится без «технической» полосы.
- Светлая тема — капсула читаема, активный пункт виден.
- Страницы товаров (`public/products/*/index.html`) — те же стили применяются автоматически.
