## План

1. **Вернуть поведение по наведению**
   - При наведении на круглую кнопку поиска будет плавно открываться то же окно/поле поиска, как при клике.
   - Lottie-анимация останется внутри круглой части и будет центрирована, без смещения вниз.

2. **Сохранить нормальную ширину**
   - Вернуть более аккуратную прежнюю ширину раскрытого поиска, чтобы он не становился слишком узким и не выглядел сломанным на текущем viewport `807x494`.
   - Dropdown будет выровнен по ширине раскрытого поля.

3. **Убрать лишнее пустое окно**
   - Не показывать блок `Начните вводить название, тип или размер…`.
   - При наведении/открытии без текста будет видно только поле поиска; результаты появятся только после ввода.

4. **Закрытие без ломания клика**
   - Поиск будет открываться на hover и по клику.
   - Закрываться будет при уходе мыши, Escape, клике вне области или очистке/потере фокуса по текущей логике.

## Технически

- Изменить только frontend-код поиска: `public/css/style.css` и `public/js/main.js`.
- Добавить CSS-состояние hover для `.search-wrap`, чтобы оно использовало ту же геометрию, что и `.is-open`.
- Уточнить JS-логику, чтобы hover мог открывать поле без показа пустого dropdown.
- Проверить результат на текущей ширине preview `807px`: hover открывает окно, Lottie стоит ровно, клик и ввод работают.
